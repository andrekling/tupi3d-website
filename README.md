# tupi3d.com

Coming-soon landing page for **Tupi3D**, a VR 3D modeling app for Meta Quest and Pico.

Static single page, served by GitHub Pages at <https://www.tupi3d.com>.
No build step — `index.html` is plain HTML with inline CSS.

## Local preview

```sh
python3 -m http.server 8000
# open http://localhost:8000
```
